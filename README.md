# Lynk

**SSH-пульт для приватных сервисов.** Подключился к узлу — и у тебя в одном месте терминал,
веб-панели на его `127.0.0.1` и обычные TCP-туннели для других приложений.

```
телефон  ──SSH──►  узел (Pi / VPS)  ──►  127.0.0.1:8123  Home Assistant
                                     ──►  127.0.0.1:3000  какая-нибудь панель
                                     ──►  127.0.0.1:5432  база
```

Ни один веб-порт при этом не торчит наружу: доступ идёт через SSH, а сервисы остаются
на loopback удалённой машины.

## Что умеет

- **Общий дашборд**: все сохранённые сервисы со всех узлов на одном экране, с favicon.
- **Открыть по порту**: ввёл `3000` — приложение подняло проброс и открыло страницу.
- **Терминал**: интерактивный SSH-шелл с xterm-эмуляцией, панелью `Esc/Tab/Ctrl/стрелки`,
  настраиваемым шрифтом и копированием буфера.
- **Туннели**: сохранённые локальные пробросы (`localhost:15432 → узел:5432`), включаются
  переключателем и живут в foreground-сервисе.
- **Безопасность**: проверка ключа сервера при первом подключении, отказ при подмене ключа,
  пароли и приватные ключи шифруются ключом из Android Keystore.

## Стек

Kotlin 2.0.21 · Jetpack Compose (Material 3) · JSch (mwiede fork) · minSdk 26 · targetSdk 35.

Стиль — строгий серый, тёмная тема, без акцентов: цвет только у состояния соединения.

## Сборка

Нужны JDK 17 и Android SDK (platform 35, build-tools 35.0.0).

```bash
# local.properties
sdk.dir=/path/to/android-sdk

./gradlew :app:assembleDebug        # debug APK
./gradlew :app:assembleRelease      # release APK (keystore.properties, если нужен подписанный)
./gradlew :app:testDebugUnitTest    # JVM-тесты эмулятора терминала
```

`gradlew` в репозитории — тонкая обёртка над локальной установкой Gradle 8.11.1
(`GRADLE_DIST=/path/to/gradle-8.11.1`). Можно заменить обычным wrapper'ом:

```bash
gradle wrapper --gradle-version 8.11.1
```

## Архитектура

```
ui/            Compose-экраны, навигация, состояние экранов (LynkState)
data/          модели, JSON-хранилище, шифрование секретов (Keystore)
ssh/           JSch: сессии, проверка ключей, локальные пробросы, терминал
service/       foreground-сервис, который держит соединения живыми
util/          favicon, форматирование
```

Один узел — одна SSH-сессия. Терминал, браузер и туннели добавляют в неё свои каналы,
а не открывают новый логин.

## Ограничения

- Приложение не открывает сервисы в интернет и не заменяет авторизацию внутри самих панелей.
- Некоторые панели плохо переносят доступ по `127.0.0.1` (жёсткие редиректы, HTTPS-сертификаты
  на домен) — им может понадобиться настройка имени хоста.
- Android может приостановить приложение в фоне; активные соединения держит foreground-уведомление.
